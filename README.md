# Desktop Pet 桌面宠物

把一张照片变成住在桌面上的专属宠物：喂食、抚摸、聊天，久坐时提醒你休息，心情不好时陪你说说话。
全部数据保存在本地，离线可用。

## 功能

- **上传照片生成宠物**：本地抠图或圆角卡片两种方式，可调容差、羽化，实时预览。
- **历史宠物**：随时查看、切换、改名、删除以前生成的宠物。
- **互动**：右键喂食（小饼干 / 苹果 / 牛奶 / 小鱼干）、摸摸头、查看状态；宠物有饱腹、心情、亲密度。
- **陪伴**：双击宠物打开聊天，提供心情快捷选项和深呼吸引导；默认离线话术，可选接入大模型。
- **休息提醒**：连续使用电脑 50 分钟（可调）后气泡提醒，键鼠静止 5 分钟以上不打扰。
- **心情问候**：默认每 2 小时主动问一句，点击气泡即可聊天。
- **开机自启动**：设置中勾选即可，随时可取消。

## 快速开始

1. 首次使用双击 **`setup.bat`** 安装依赖（只需 Pillow）。
   > 已装过依赖可跳过。也可以在命令行执行 `python -m pip install -r requirements.txt`。
2. 双击 **`run.bat`** 启动。
3. 宠物出现在屏幕右下角，首次启动会打开“生成我的专属宠物”窗口。

## 使用说明

| 操作 | 效果 |
| --- | --- |
| 左键拖拽 | 把宠物放到任意位置（位置会自动记住） |
| 单击 | 摸摸头，提升心情与亲密度 |
| 双击 | 打开聊天窗口 |
| 右键 | 聊天 / 喂食 / 摸摸头 / 查看状态 / 给宠物取名 / 换宠物 / 添加宠物 / 设置 / 退出 |

**退出程序**：右键宠物 → 退出。开机会自动出现的前提是勾选了“开机自动启动”。

### 生成自己的宠物

1. 右键 → 添加新宠物…（或“我的宠物”窗口右上角）；
2. 选择照片。建议主体清晰、背景干净（宠物、玩偶、人像都可以）；
3. 默认“自动抠图”，背景去不干净时提高容差；边缘发毛时降低羽化；背景太杂可切换“保留原图卡片”；
4. 填好名字，点“生成宠物”。生成后会自动切换成新形象，旧宠物保存在历史列表中。
5. 之后想改名：右键宠物 → 给宠物取名…；也可在“我的宠物”窗口中点“改名”。

### 接入大模型（可选）

设置 → 陪伴对话：

- 接口地址：OpenAI 兼容地址，例如 `https://api.deepseek.com/v1`
- API Key：你的密钥
- 模型名称：例如 `deepseek-chat`
- 勾选“启用大模型对话”，点“测试连接”确认可用后保存。

不填也能正常使用，此时由内置的本地话术陪伴。Key 只保存在本机 `data/config.json`。

## 数据与备份

所有数据都在程序目录的 `data/` 下：

- `config.json`：设置
- `pets.json`：宠物列表
- `state.json`：当前宠物、养成数值、聊天记录
- `pets/<id>/`：宠物形象与缩略图
- `app.log`：运行日志（排查问题用）

备份或换电脑时，直接复制整个文件夹即可；想恢复初始状态，退出程序后删除 `data/` 再启动。

## 常见问题

**启动时闪一下就没反应？**
程序只允许运行一个实例，先看看屏幕右下角或任务管理器里是否已有 Python 进程；也可查看 `data/app.log`。

**抠图把宠物吃掉了一部分？**
提高“抠图容差”或改用“保留原图卡片”；主体与背景颜色太接近时，抠图本身有局限。

**开机没有自动出现？**
打开设置确认“开机自动启动”已勾选；部分安全软件会拦截注册表写入，需要放行。

**任务栏没有图标，怎么退出？**
右键宠物 → 退出。程序是透明小窗口，不会占用任务栏。
